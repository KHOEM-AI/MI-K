# 3D Models (GLB)

Put `.glb` files here. The app loads them at these exact paths.

## Structure


File names must match exactly — e.g. `public/models/animals/horse.glb`.

## Free sources (CC0 / CC-BY)

- **Sketchfab** — https://sketchfab.com/3d-models?features=downloadable (filter by CC-BY or CC0)
- **Poly Haven** — https://polyhaven.com/models (all CC0)
- **Quaternius** — https://quaternius.com/ (low-poly, CC0)
- **Kenney** — https://kenney.nl/assets?q=3d (CC0)
- **Free3D** — https://free3d.com/ (mixed licenses)
- **Khronos Samples** — https://github.com/KhronosGroup/glTF-Sample-Models (test models)

## Scale

Auto-fits per category — you don't need to rescale the source:
- **animals**: 2.5 m
- **houses**: 6 m
- **tools**: 1.2 m
- **vehicles**: 2.5 m

## Steps

1. Download `.glb` (embedded textures only — avoid `.gltf` + separate files).
2. Rename to match the expected filename.
3. Copy into the right folder.
4. Reload the page → real model loads automatically.
