# KHOEM-AI Character Library

Store 3D character assets here.

Supported model format:
- GLB (.glb)
- Rigged human characters
- PBR textures
- Skeletal animations

Character requirements:
- Full body mesh
- Head, face, hands and fingers
- Legs and feet
- Skeleton / armature
- Suitable animation rig

Do not use placeholder mannequins as final characters.

## File names used by the People tab

The People tab (KHOEM-AI 3D) loads `/characters/<id>.glb` for each character. Put a real model at one of these
names and it replaces the built-in test figure:

- `businessman.glb`
- `fashion-model.glb`
- `doctor.glb`
- `businesswoman.glb`
- `student.glb`
- `nurse.glb`

The portraits on the cards are drawn in SVG by the app, so no image files are needed.
